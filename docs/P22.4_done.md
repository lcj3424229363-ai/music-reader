## 1. 目标

消除 app.js 里 6 套视觉/逻辑坐标和 4 套索引/状态散落导致的"坐标契约混乱"：

- 同一份"鼠标 x 距离 stave 起点"用 4 个不同字段名（`geometry.x / noteStartX / startX / staveX`）独立算 4 次
- 同一份"音高 y → step+octave"在 pitchFromY 内联，cs 自己又写一遍
- 同一份"beat 计算"内联在 renderGhost / hover / refresh 三处

把"坐标转换"关进 `CoordinateSystem` 单一类，业务只调 `cs.*` 不直接读 geometry 字段。

## 6. CoordinateSystem v1 公开 API（最终版）

### Layout（像素几何）
- `viewportToCanvas(event, canvas)` → `{x, y}`
- `staffAtPoint(x, y)` → `{staveKey, geometry, measureIndex, measureRect} | null`
- `canvasToStave(x, y, geometry)` → `{localX, localY}`
- `canvasToBeat(x, geometry, meter)` → `{beat, beatWidth, targetX}`
- `beatToCanvasX(beat, geometry, meter)` → `number`
- `isInNoteRange(localX, geometry)` → `boolean`
- `isInPitchRange(localY, geometry)` → `boolean`

### Music（音乐语义）
- `localYToPitch(localY, staveKey, geometry)` → `{step, octave}`
- `unitsForDuration(duration, dotted)` → `number`
- `unitsForEntry(entry)` → `number`
- `sumUnits(entries)` → `number`
- `exceedsUnits(left, right)` → `boolean`
- `sameUnits(left, right)` → `boolean`
- `normalizeUnits(value)` → `number`
- `capacity()` → `number`

### Lifecycle
- `updateLayout({staffGeometry, trebleGeometry, bassGeometry, measureRects, currentMeasureIndex, timeSignature})`
- `clearLayout()`

### Internal（测试 only）
- `_internal.layout` → LayoutGeometry 实例
- `_internal.music` → MusicMapping 实例
