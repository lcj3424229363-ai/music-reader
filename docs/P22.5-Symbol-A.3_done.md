## TL;DR

A.3 修复"跨 measure 的 tie/slur/phrase/hairpin 找不到 target、画不出来"。**根因**: 8 个查询函数 + 4 个绘制函数全部基于 `notationEntries` (单 measure 局部数组), 跨 measure 时 `for` 循环跑完找不到。

**A.3 落地的 5 件事**:

1. **数据层 — 新增 `buildScoreEntries()`** (L3075, ~20 行)
   - 全局 flatten 索引, 每个 entry 挂 `_globalIndex / _measureIndex / _localIndex`
   - 通用支持: `measure.notationEntries` / `measure.entries` / `measure` 本身是 array (trebleState 用)

2. **8 个查询函数改全局** (L3384+):
   - `nextTieTargetIndex` / `previousTieSourceIndex`
   - `nextSlurTargetIndex` / `previousSlurSourceIndex`
   - `nextHairpinStopIndex` / `nextHairpinStopSourceExists`
   - `nextPhraseTargetIndex` / `nextPhraseSourceExists`
   - 全部: 形参 `notationEntries` → `scoreEntries`, 行为不变 (scoreEntries 是全局, 跨 measure 自动找)

3. **4 个绘制函数改接受 (scoreEntries, notesByMeasure) [+ stavesByMeasure for hairpin]** (L3351+ / L3436+ / L3475+ / L3593+):
   - 同 measure: 走 VexFlow 原生
   - 跨 measure: 走 raw SVG path fallback (新 helper)

4. **4 个跨 measure helper** (L3100+, ~80 行):
   - `drawCrossMeasureTie` / `drawCrossMeasureSlur` / `drawCrossMeasurePhraseMark` / `drawCrossMeasureHairpin`
   - 用 `note.getTieRightX/getTieLeftX` 算绝对 x
   - 用 `boundingBox.y/h` 算 y
   - 弧度递增: tie (6px) < slur (12px) < phrase (20px)
   - 调 VexFlow context: openGroup/beginPath/quadraticCurveTo/lineTo/stroke/closeGroup

5. **渲染循环改造** (L2254+ / L2326+ / L2775+ / L2873+):
   - 单谱表 `renderSingleNotationSafe`: 主循环外 build `notesByMeasure` + `stavesByMeasure`, 主循环内每个 measure 把自己的 notes push 进去
   - 单谱表主循环结束后调 4 跨音符 draw (用全局 `buildScoreEntries(scoreMeasures)`)
   - 4 部画布 (双谱表 piano 模式): treble / bass 各自 build `notesByMeasure` + `stavesByMeasure`, 各自调 4 跨音符 draw (用 `buildScoreEntries(trebleState.measures)` / `buildScoreEntries(bassState.measures)`)
   - `drawStaffEntriesOnStave` 新签名: `function drawStaffEntriesOnStave(context, stave, entriesSource, clef, width, selectable, measureIndex, notesByMeasure, stavesByMeasure)`
   - `drawStaffEntriesOnStave` 内部: 删 4 跨音符 draw 调用, 收集 notes + stave, 留 `drawEntryArpeggios` (单 note, 不跨 measure)

## 已知 A.3 限制 (接受)

1. **跨 measure 几何精度** — raw SVG path 二次贝塞尔曲线手算的 y 弧高, 跟 VexFlow 内部算法不严格一致, 但视觉接近 (VexFlow 限制)
2. **跨 system (跨行) tie/slur/phrase/hairpin 暂不画** — 渲染主循环是 1D 线性 (单行), 跨行会 break。P22.5-Symbol 范围 = 跨 measure (同行), 跨 system 是另一个问题
3. **跨 measure hairpin y 简化** — 用 entry stave 的 `getYForLine(4) + 8`, 假设 target 在同一行 (渲染主循环 1D 线性, 实际成立)
4. **`buildScoreEntries` 浅拷贝** — `...entry` 是浅拷贝, entry 嵌套对象 (如 `pitches[].accidental`) 引用同一对象。render 时 build 一次, 期间数据不变, 安全; 但**修改 entry 后必须重 build**
5. **业务层 `toggleSelectedFlag` 保留 measure 局部** — 用户 toggle tieStart/tieStop 时只在当前 measure 找 target (L3975/3980 仍用 `measureEntries[selectedEntryIndex]`)。跨 measure 业务触发**不接 A.3**, 因为 toggle UI 只能点在当前 measure 的 entry 上
6. **双谱表 4 部画布用单 measure 局部 `scoreEntries`** — 4 部画布只显示 current measure, 不存在跨 measure 业务, 简化实现: `buildScoreEntries(trebleState.measures)` 已经处理 (`measure` 是 array)
