#### D.1 DCML Harmony Schema 版本兼容 (补充-1 修订)

**事实**: DCML 不同 repo 用了不同 harmony schema 版本 (来自 P20.3.10 audit):
- `2.3.0` (新版, 大多数 repo): Mozart K545, Beethoven Op.13, Schumann Kinderszenen, Chopin Mazurkas, Grieg, Tchaikovsky, Mahler KdL, Debussy Berg.
- `2.1.0` (旧版): ABC (Beethoven quartets), Mendelssohn quartets, Ravel Jeux d'eau
- (无标注): Beethoven Op.27-2 (Moonlight), Beethoven Op.106 (Hammerklavier) — labels=0, 不可用

**Adapter 契约**: 必须同时解析 2.1.0 和 2.3.0 两种 schema。差异点:
- 2.3.0 新增 `mc_onset` 列 (chord 在 measure 内偏移)
- 2.1.0 没有 `mc_onset`, 默认 onset=0
- 字段名 `cadence` 在 2.1.0 偶尔写 `cad`, 2.3.0 统一 `cadence`

**实现要求** (P20.3.13):
- `DCMLAdapter` 启动时自动检测 schema 版本 (读 README standard 行)
- `get_harmonies()` 返回统一 `HarmonyLabel` dataclass, 内部 normalize
- 测试覆盖: 至少 1 个 2.1.0 case (Ravel) + 1 个 2.3.0 case (K545) 端到端

#### D.2 License Gate (补充-3 修订: **设计方案, 非现有事实**)

**当前事实**: `data/eval/` 没有任何 license gate 代码。**未来 P20.3.13 才实现**。

**设计方案 (P20.3.13 实施)**:
- `data/eval/adapters/license_gate.py` 创
- CC-BY-NC-SA-4.0 必须用户首次显式同意, 否则不下载
- 同意文件: `~/.cache/mtre/license_accepted.json` 存 SHA256 摘要 + 时间戳
- 第二次运行: 静默通过 (不再问)

**契约 (P20.3.13 必实现)**:
- 输入: `license_id: str` (如 "CC-BY-NC-SA-4.0")
- 输出: `LicenseAcceptance` 对象 (accepted: bool, accepted_at: str, summary_sha256: str)
- 错误: 抛 `LicenseNotAcceptedError` (如果用户拒绝)

**Manifest → Adapter 调用链 (设计, P20.3.13 实施)**:
```
manifest.json case entry
  → license_gate.check(license_id) → accepted?
    → DCMLAdapter(repo_url, commit_sha)
      → get_harmonies(case.score_file) → ground truth Roman numerals
        → Agent.run(case.input) → predicted Roman numerals
          → benchmark.compare(predicted, ground_truth) → accuracy
```

```python
# 伪代码, P20.3.12 实施 (X3 修订: 同时处理 gold + later_profiles)
from glob import glob
import json
import shutil
import os

SOURCES = [
    {
        "glob": "data/eval/gold/*.json",
        "archive_dir": "data/eval/_archive/P20.3/gold/",
        "deprecated_reason": "P20.3 audit: framework=positional (sposobin); superseded by DCML Tier A",
        "label": "legacy_gold",
    },
    {
        "glob": "data/eval/later_profiles/*.json",
        "archive_dir": "data/eval/_archive/P20.3/later_profiles/",
        # 原因因文件而异, 见 3.6 表 (autumn_leaves=ML/B, debussy_faun=C, ravel_jeux_deau=与 V1 case 19 重复, so_what=jazz)
        # 实际写时按文件名匹配:
        "deprecated_reasons": {
            "autumn_leaves.json": "Tier B (machine-generated, not expert-annotated); superseded by DCML Tier A for V1 benchmark",
            "debussy_faun.json": "Tier C (raw score only, no Roman numeral annotation); superseded by DCML Tier A for V1 benchmark",
            "ravel_jeux_deau.json": "DEPRECATED: duplicate of V1 case 19 (DCML DCMLab/ravel_piano, 85m/257 labels, framework=functional); old positional framework (sposobin) not comparable",
            "so_what.json": "Tier B (jazz modal harmony, non-classical Roman numeral system); superseded by DCML Tier A for V1 benchmark",
        },
        "label": "later_profiles",
    },
]

# 1. Archive 所有 source (X3: 两个目录都 copy, 不 move)
for src in SOURCES:
    os.makedirs(src["archive_dir"], exist_ok=True)
    for json_file in glob(src["glob"]):
        target = os.path.join(src["archive_dir"], os.path.basename(json_file))
        shutil.copy2(json_file, target)  # copy 不 move

# 2. 写 provenance.deprecated 4 字段 (B1 决定, 在 Provenance 下)
for src in SOURCES:
    for json_file in glob(src["glob"]):
        with open(json_file) as f:
            data = json.load(f)
        if "provenance" not in data:
            data["provenance"] = {}
        # B1: 不放 EvalCase 顶层, 全在 Provenance
        data["provenance"]["deprecated"] = True
        # 原因因 source 而异
        if "deprecated_reasons" in src and os.path.basename(json_file) in src["deprecated_reasons"]:
            data["provenance"]["deprecated_reason"] = src["deprecated_reasons"][os.path.basename(json_file)]
        else:
            data["provenance"]["deprecated_reason"] = src["deprecated_reason"]
        data["provenance"]["deprecated_at"] = "2026-08-XX"
        data["provenance"]["deprecated_by"] = "P20.3.12"
        with open(json_file, "w") as f:
            json.dump(data, f, indent=2, ensure_ascii=False)
```

**关键 (X3)**:

- 3 个非 DEPRECATED later_profiles (autumn_leaves / debussy_faun / so_what) 也写 deprecated=True, 因为 B4 决定它们是 Tier B/C 不进 V1, 等同退役
