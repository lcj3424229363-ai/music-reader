## 6 个 toJSON API

```js
// 1. Note.toJSON() — 30 字段 (7 基础 + 20 修饰符 + 3 tuplet)
Note.prototype.toJSON() → {
  id, kind, voice, pitches, duration, dotted, units,
  articulation, fingering, textMark, ornament, fermata, grace,
  dynamic, pedal, breath,
  tieStart, tieStop, slurStart, slurStop,
  phraseStart, phraseStop, hairpin,
  chordSymbol, arpeggiate, volta, rehearsalMark,
  tupletType, tupletGroup, tupletPosition
}

// 2. Relation.toJSON() — 含 members 顶层字段 + payload
Relation.prototype.toJSON() → {id, type, from, to, members, payload}

// 3. Voice.toJSON() — notes 数组递归调 note.toJSON
Voice.prototype.toJSON() → {id, role, notes}

// 4. Measure.toJSON() — voices 数组递归
Measure.prototype.toJSON() → {index, number, timeSignature, beginBarline, endBarline, voices, tempo, directions, volta, rehearsalMark}

// 5. Part.toJSON() — measures 数组递归
Part.prototype.toJSON() → {id, name, instrument, staves, measures}

// 6. Score.toJSON() — meta + parts + relations 顶层
Score.prototype.toJSON() → {meta, parts, relations}

// 7. scoreFromJSON(json) — 反序列化
ScoreModel.scoreFromJSON(json) → Score
// 接受 {meta, parts, relations} 形状 (裸对象, 不接 schemaVersion 包装)
// 递归还原 Part → Measure → Voice → Note + Relation
// Note instance 类名保留 (note.constructor.name === "Note")
```

## 已知 B.4 限制 (接受)

1. **不接 schemaVersion 包装** — B.4 输出裸对象, 业务层自己包
2. **MusicXML 不动** — app.js 走 documentData, Score Model 跟它完全独立
3. **浅拷贝** — pitches / members / grace 改 JSON 不影响原 instance, 但嵌套对象内部是共享的 (B.4 接受)
4. **空 json 接受** — `scoreFromJSON({})` 返空 Score, 不抛错
5. **tuplet 跨 measure 不支持** — B.3 决策 6 留口, B.4 序列化照存, 不自动生成跨 measure 关系
