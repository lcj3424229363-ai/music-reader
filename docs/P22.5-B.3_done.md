## 4 helper 扩展 API

```js
// 1. buildRelations (B.3 通用化)
buildRelations(score, types) → Relation[]
  // types: undefined | "tie"|"slur"|"phrase"|"tuplet"|[...]
  //   - undefined → 默认 4 种全扫
  //   - [] → 空扫 (啥都不生)
  //   - ['tie'] → 只 tie
  // tie: tieStart → tieStop (跨 measure 找, 不允许跨 voice)
  // slur: slurStart → slurStop (允许跨 voice)
  // phrase: phraseStart → phraseStop (允许跨 voice)
  // tuplet: 按 tupletGroup 聚合 → 1 Relation
  //   {type: "tuplet", members: [noteId1, ...], payload: {actual, normal}}

// 2. validateRelations (B.3 扩)
validateRelations(score) → {valid: bool, errors: [], warnings: []}
  // errors: 硬错
  //   - from/to 找不到
  //   - tie from/to 不同 pitch
  //   - tie 跨 voice
  //   - tuplet members.length 跟 actual 不一致
  //   - tuplet 跨 voice
  //   - tuplet members 找不到
  // warnings: 软提示
  //   - slur 跨 voice (B.3 决策 4)

// 3. syncEntryFromRelation (B.3 扩)
syncEntryFromRelation(score, rel) → bool
  // tie: from.tieStart=true, to.tieStop=true
  // slur: from.slurStart=true, to.slurStop=true  (B.3 新)
  // phrase: from.phraseStart=true, to.phraseStop=true  (B.3 新)
  // tuplet: 不接, 返 false (业务侧管 group)

// 4. legacyToNote (B.3 改名 + 补字段)
legacyToNote(legacy, voiceId, partId, measureIndex, noteIndex) → Note
  // 原名 legacyEntryToEntry
  // 18 修饰符字段 + 3 tuplet 字段 (B.3 补)

// 5. noteToLegacyNote (B.3 改名)
noteToLegacyNote(note) → legacyObj
  // 原名 entryToLegacyEntry
  // for-in 拷全部, 剥 _ 前缀字段
```
