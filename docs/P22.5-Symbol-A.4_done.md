## TL;DR

A.4 落地 3 件事:

1. **entry 字段全初始化 (新发现的根因)** — 18 个修饰符字段在 entry 创建时只有 2 个 (fermata/dynamic) 有默认值, 其余 16 个 undefined。导致 entry 间比较/序列化/solver 端读字段不稳。新增 `ENTRY_MODIFIER_DEFAULTS` 常量 + `ensureEntryDefaults()` helper, 渲染前自动补全 (idempotent, 已有不覆盖)。

2. **段标 (rehearsal mark) 渲染** — entry 字段 `rehearsalMark: ""`, VexFlow.RehearsalMark 在 measure 第一音上方画方框 (A/B/C/Intro/Verse 1...)。

3. **volta 1./2./3. ending 渲染** — entry 字段 `volta: 1|2|3|null`, VexFlow.Repetition 在 repeat-begin 时画 volta 括号 + 编号。

## ENTRY_MODIFIER_DEFAULTS 18 字段 (按 slot 分)

```js
const ENTRY_MODIFIER_DEFAULTS = Object.freeze({
  // ABOVE slot
  articulation: "",   // 跳音/重音/tenuto/marcato
  fingering: "",      // 1-5
  textMark: "",       // 自由文本
  ornament: "",       // trill/mordent/turn/...
  fermata: false,
  // grace 单独
  grace: null,        // {step, octave, accidental} | null
  // BELOW slot
  dynamic: "",        // p/f/mf/mp
  pedal: "",          // start | ""
  breath: false,
  // 跨音符
  tieStart: false, tieStop: false,
  slurStart: false, slurStop: false,
  phraseStart: false, phraseStop: false,
  hairpin: "",        // "cresc-start" | "decresc-start" | "stop" | ""
  // 文本 / 演奏法
  chordSymbol: "",    // "C", "Am", "G7"
  arpeggiate: false,
  // A.4 曲式
  volta: null,        // 1 | 2 | 3 | null
  rehearsalMark: ""   // "A" / "B" / "Intro" / "Verse 1"
});
```

## 已知 A.4 限制 (接受)

1. **rehearsal mark per entry, 但通常 1 measure 1 个** — 用户在 entry 上设, 渲染时 find 第一个有 note 的 entry 用
2. **volta 默认 per measure** — UI 是 select, 用户在 entry 上设数字, 渲染时 find 第一个有 volta 的 entry
3. **ensureEntryDefaults 是"懒"补全** — 第一次渲染才补, 期间 entry 数据不带默认值。`JSON.stringify` entry 序列化时仍可能丢字段 (因为 spread 没动)
4. **`buildScoreEntries` 浅拷贝丢失 _ 前缀字段** — A.3 已说明, A.4 沿用, 不修
5. **VexFlow.RehearsalMark 跟 VexFlow 4.x 实际 API 可能略有差异** — 浏览器实测需 user 验证
